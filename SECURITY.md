# Security policy

**Reporting a vulnerability.** Please email the address listed in [`/.well-known/security.txt`](.well-known/security.txt) (`correoSeguridad` in `legal-config.js`). Do not open a public issue for security problems. We aim to acknowledge reports within 3 business days.

**In scope:** this repository and the deployed app (`index.html` and the static pages), the Supabase schema and policies in the `.sql` files.

**Please don't:** access or modify data of clinics that aren't yours, run denial-of-service tests, or test with real patient data.

**Incident response:** see [`docs/RESPUESTA-A-INCIDENTES.md`](docs/RESPUESTA-A-INCIDENTES.md) (Spanish).

**Compliance plan (Mexico, LFPDPPP):** see [`docs/PLAN-LEGAL-MX.md`](docs/PLAN-LEGAL-MX.md).
